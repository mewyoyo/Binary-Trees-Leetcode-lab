94. Binary Tree Inorder Traversal

1. Problem
Given the root of a binary tree, return the inorder traversal of its nodes' values (Left -> Root -> Right).

2. Approach
Use Depth-First Search (DFS) recursion with a helper method and a result list:
- Base case: If the current node is null, return.
- Traverse left: Recursively call inorder(node.left, result).
- Visit root: Add the current node's value to the list using result.add(node.val).
- Traverse right: Recursively call inorder(node.right, result).

Tracing Example (root = [1, null, 2, 3])
- Start at node 1: left child is null -> add 1 to result -> move right to node 2.
- At node 2: move left to node 3.
- At node 3: left child is null -> add 3 to result -> right child is null -> return to node 2.
- Back at node 2: add 2 to result -> right child is null -> finish.
- Result: [1, 3, 2].

Challenges Faced & Failed Approaches
1. Issues with inorder(root, result);
- Mistake: Accidentally passing root instead of node.left or node.right inside the recursive helper method, or calling inorder(root, result) repeatedly without advancing down the tree.
- Why it failed: The recursion stayed stuck on the root node, causing a StackOverflowError.
2. Issues with result.add(node.val);
- Mistake: Placing result.add(node.val) in the wrong position (before traversing left or after traversing right) or accessing node.val before checking if node == null.
- Why it failed: Wrong placement produced preorder or postorder traversal instead of inorder, while missing the null check caused a NullPointerException.

3. Time Complexity
Time Complexity: O(n)
- Each of the n nodes in the tree is visited once.

Space Complexity: O(n)
- O(n) in the worst case (skewed tree) and O(log n) on average (balanced tree) due to the recursion call stack.

4. Reflection / Improvement
- Is there a better approach? Both recursive and iterative (using an explicit Stack) solutions run in O(n) time and O(n) space.
- Alternative: Morris Traversal achieves O(1) extra space by temporarily linking predecessors, though recursion is much simpler and easier to read.
- Best Complexity: O(n) Time, O(n) Space (or O(1) Space with Morris Traversal).
