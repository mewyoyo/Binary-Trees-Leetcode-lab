104. Maximum Depth of Binary Tree

1. Problem
Given the root of a binary tree, return its maximum depth (the number of nodes along the longest path from the root node down to the farthest leaf node).

2. Approach
Use Depth-First Search (DFS) recursion:
- Base case: If root is null, return 0.
- Recursive step: Recursively compute the maximum depth of the left subtree (leftDepth) and right subtree (rightDepth).
- Combine: Return 1 + Math.max(leftDepth, rightDepth) to count the current node plus the deeper subtree.

Tracing Example (root = [3, 9, 20, null, null, 15, 7])
- Leaf nodes 9, 15, and 7: left and right children are null (return 0) -> each returns 1 + Math.max(0, 0) = 1.
- Node 20: receives 1 from left (15) and 1 from right (7) -> returns 1 + Math.max(1, 1) = 2.
- Root node 3: receives 1 from left (9) and 2 from right (20) -> returns 1 + Math.max(1, 2) = 3.
- Result: 3.

Challenges Faced & Failed Approaches
1. Issues with recursive subtree calls (int leftDepth = maxDepth(root.left); int rightDepth = maxDepth(root.right);)
- Mistake: Forgetting to store/return the recursive call results or accidentally passing root instead of root.left / root.right.
- Why it failed: Failing to capture the returned values lost the depth calculation, while passing root caused infinite recursion (StackOverflowError).
2. Issues with combining depths (return 1 + Math.max(leftDepth, rightDepth);)
- Mistake: Forgetting the + 1 for the current node, or adding leftDepth + rightDepth instead of using Math.max.
- Why it failed: Omitting + 1 caused every call to return 0, while summing both sides counted total nodes in the tree instead of the maximum depth.

3. Time Complexity
Time Complexity: O(n)
- Each of the n nodes in the tree is visited once.

Space Complexity: O(n)
- O(n) in the worst case (skewed tree) and O(log n) on average (balanced tree) due to the recursion call stack.

4. Reflection / Improvement
- Is there a better approach? Recursive DFS is optimal and the cleanest way to solve this problem in O(n) time.
- Alternative: Iterative Breadth-First Search (BFS) using a Queue counts levels without recursion, running in O(n) time and O(n) space.
- Best Complexity: O(n) Time, O(n) Space (worst case) / O(log n) Space (balanced).
